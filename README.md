Partner REST API for iCallAgent, a platform for building and operating AI voice agents that hold real-time phone/web conversations via an ASR-LLM-TTS pipeline. The API lets third-party apps act on a user's workspace: managing agents, outbound campaigns, contacts, phone numbers, and webhooks.

**Areas:** Voice AI · voice ai assistant · Conversational AI · Voice Agents · telephony / CPaaS · contact center / CCaaS · Outbound Calling · speech (ASR/TTS) · agent tools / MCP

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for iCallAgent Public API: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
