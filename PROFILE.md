# iCallAgent Public API

Partner REST API for iCallAgent, a platform for building and operating AI voice agents that hold real-time phone/web conversations via an ASR-LLM-TTS pipeline. The API lets third-party apps act on a user's workspace: managing agents, outbound campaigns, contacts, phone numbers, and webhooks.

- **Provider:** https://icallagent.com
- **Documentation:** https://docs.icallagent.com/
- **Base URL:** https://api.icallagent.com/api/public/v1/

## APIs

- **iCallAgent Public API** — Documented, versioned REST API for managing AI voice agents, outbound campaigns, contacts, phone numbers, and webhook subscriptions. Authenticated via personal API key (ic_live_) or OAuth2 bearer tokens. (`https://api.icallagent.com/api/public/v1/`)

> Primary consumable interface is the REST API with a publicly retrievable OpenAPI 3.0.3 contract at https://docs.icallagent.com/openapi.json (real API host: api.icallagent.com/api/public/v1/). iCallAgent does run an MCP server (SSE transport: GET /api/mcp/sse, POST /api/mcp/messages/), but it is runtime-internal, gated by a runtime-issued secret, and explicitly not meant for connecting arbitrary MCP clients — so it is NOT cataloged as a public MCPServer property. No llms.txt and no published agent skills were found; therefore agent_native=false. No AsyncAPI, GraphQL, or public Postman collection found. SDKs (Node/Python) are planned but not published.
